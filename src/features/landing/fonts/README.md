# Landing fonts

## Manrope

Manrope is by the Manrope Project Authors. The unmodified Latin variable WOFF2
asset (weights 400–800, 24,532 bytes) is the display and body family on
the public landing page only. It is loaded with `next/font/local` and scoped via
`--font-landing-sans`; login and workspace typography remain independent.

- [Official Google Fonts catalog](https://fonts.google.com/specimen/Manrope)
- [Official stylesheet](https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap)
- [Exact font asset](https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2)
- [Upstream license](https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt)
- SHA-256: `8c2def024c1bf31aacf3624ae3c4d701269b4ec3dc765c04830839f0d36b2d9e`

The SIL Open Font License 1.1 is included in `Manrope-OFL.txt`.

## Petrona italic

Petrona is by the Petrona Project Authors. This unmodified Latin variable italic
asset (weights 400–600) supplies brief human emphasis, not primary body copy.

- [Google Fonts catalog](https://fonts.google.com/specimen/Petrona)
- [Official stylesheet](https://fonts.googleapis.com/css2?family=Petrona:ital,wght@1,400..600&display=swap)
- [Exact asset](https://fonts.gstatic.com/s/petrona/v38/mtG44_NXL7bZo9XXgXdot0MV8ia-Fg.woff2)
- [Upstream license](https://github.com/google/fonts/blob/main/ofl/petrona/OFL.txt)

Its license remains in `OFL.txt`. Both font files are self-hosted. Visitors make no
font request to Google, and builds need no external font download.
